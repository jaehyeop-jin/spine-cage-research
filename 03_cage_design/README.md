# 03. 케이지 설계

## 선정 방향

- **수술 접근/유형:** OLIF (Oblique Lumbar Interbody Fusion) 참고
- **케이지 형상:** 일반 경사형 모델을 자체 작성하는 방향
- **참고 제품:** Medtronic CLYDESDALE / OLIF25 제품 자료
- **설계 원칙:** 제품을 그대로 복제·검증된 것으로 간주하지 않고, 공개 규격과 기존 L4–L5 형상에 맞춰 연구용 CAD를 구성한다.

## 설계 항목별 종합표

| 항목 | 적용·선정 기준 | 상태 |
|---|---|---|
| 기본 외형 | CLYDESDALE / OLIF25 참고, 연구용 형상 자체 모델링 | 방향 설정 |
| 길이 | L4 하부·L5 상부의 유효 지지 범위 측정 후 카탈로그 후보 규격 비교 | 미확정 |
| 폭 | 케이지 배치 위치에서 종판 지지 폭과 제품 규격 비교 | 미확정 |
| 높이 | L4–L5 추간 높이 및 목표 복원 높이 검토 후 선정 | 미확정 |
| 전만각 | L4·L5 종판의 상대 경사와 정렬 목표, 제품 후보 각도 비교 | 미확정 |
| 상·하 접촉면 | 골성 종판과의 실제 지지 영역·형상 적합성 확인 | 검토 중 |
| 재료 | 선택한 참고 제품과 해석 목적에 맞춰 별도 결정 | 미확정 |
| CAD | 측정·규격 선정 완료 후 제작 | 미착수 |
| 구조 검증 | 연구용 CAD의 강도·접촉/메시 안정성은 별도 검증 필요 | 미착수 |

> **주의:** 특정 길이·폭·높이·각도 수치는 아직 모델 측정으로 확정되지 않았다. 카탈로그에 규격이 있다고 해서 해당 L4–L5 모델에 적합하다는 뜻은 아니다.
