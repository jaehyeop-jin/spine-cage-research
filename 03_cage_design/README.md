# OLIF 케이지 설계

**현재 방향:** 기존 L4–L5 모델에 맞춰 일반 경사형 OLIF 케이지를 설계한다. Medtronic CLYDESDALE / OLIF25는 제품 규격·형상 참고자료이며, 제품 성능을 검증한 것으로 간주하지 않는다.

| 항목 | 선정 기준 | 상태 |
|---|---|---|
| 기본 형상 | CLYDESDALE / OLIF25 참고, 연구용 형상 자체 구성 | 방향 확정 |
| 길이 | 삽입 방향의 종판 유효 지지 범위 측정 후 후보 규격 비교 | 미확정 |
| 폭 | 배치 위치의 종판 지지 폭과 후보 규격 비교 | 미확정 |
| 높이 | L4–L5 추간 높이 및 목표 복원 높이 검토 | 미확정 |
| 전만각 | 종판 상대 경사와 정렬 목표 검토 | 미확정 |
| 접촉면 형상 | L4 하부·L5 상부 골성 종판과의 실제 적합성 검토 | 검토 중 |

**현재 판단:** 후보 치수는 아직 측정으로 검증하지 않았다. 제품 카탈로그의 규격이 존재한다는 이유만으로 해당 모델에 적합하다고 보지 않는다.
