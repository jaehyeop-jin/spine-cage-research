# 06. 참고자료

원문을 확인한 자료, 현재 단순 참고 중인 자료, 적용 수치의 근거를 구분하여 기록한다.

| 구분 | 자료 | 현재 용도 | 확인 상태 |
|---|---|---|---|
| 제품 문서 | [Medtronic OLIF25 수술 절차 안내 PDF](https://thespinemarketgroup.com/wp-content/uploads/2020/07/OLIF25-Procedure.SGT-Medtronic.pdf) | CLYDESDALE 계열의 OLIF 절차 및 제품 규격 검토 | 사용자 제공 링크; 제품·사양 적용 전 원문 대조 |
| 논문 | [Zou 등, DOI: 10.1177/21925682231166612](https://doi.org/10.1177/21925682231166612) | 기존 해석 블록도에 기재된 재료 물성 참고 | 기존 블록도 기록; 수치와 적용 조건 원문 재확인 필요 |

## 인용 관리 기준

1. **카탈로그:** 제조사, 문서명, 발행/개정, 제품 모델, 규격표의 페이지를 기록한다.
2. **논문:** 저자, 연도, 제목, DOI와 실제 인용한 표·그림·페이지를 기록한다.
3. **표준:** 표준번호와 판(발행 연도)을 기록하며, 시험을 시행한 것처럼 표현하지 않는다.
4. **연구 내부 기록:** 모델·형상·규격·물성 등 각 결론을 해당 출처와 연결한다.

현재 표는 검토 자료 목록이며, 원문 대조와 수치 검증이 완료된 참고문헌 목록은 아니다.
