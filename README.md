> **기준일:** 2026-10-19 · **상태:** 연구 설계·모델 선정 검토 단계  
> **기록 원칙:** 합의된 방향과 실제 검증·완료를 구분한다. 미측정 수치·미수행 해석을 확정 결과로 기록하지 않는다.

## 관리 기준

1. **README(종합표):** 현 시점의 결론과 작업 상태만 기록한다.
2. **카테고리 문서:** 적용 기준, 측정·모델링 방법, 미해결 항목을 상세화한다.
3. **참고자료:** 수치나 방법이 의존하는 원문 링크·출처를 연결한다.
4. **[DECISIONS.md](DECISIONS.md):** 중요 결정의 날짜, 선택 근거, 보류 사유를 기록한다.
5. **Git 커밋:** 의미 있는 문서 변경 단위로 한국어 메시지를 남긴다.

**상태 정의:** 확정 = 연구에서 사용할 방향 결정 / 잠정 = 적용 예정이나 추가 근거·검증 필요 / 검토 중 = 결정 전 / 미착수 = 실행 전. 방향 '확정'은 구조 성능이나 임상 적합성이 검증되었다는 의미가 아니다.

**파일 보관:** Markdown·도면·경량 데이터는 Git으로 버전 관리하고, 대용량 CAD/FEA 결과를 추가할 때는 Git LFS 또는 별도 저장소 정책을 검토한다.
