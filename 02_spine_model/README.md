# 02. 척추 모델

## 모델 현황

| 항목 | 현재 결론 | 상태 |
|---|---|---|
| 모델 출처 | 기존 FEBio 기반 요추 모델(Finley 등 모델 계열) | 기존 사용 모델 |
| 대상 | L4–L5 | 확정 |
| 원본 CT | 현재 미확보 | 확인 필요 |
| 치수 선정에 사용할 형상 | L4 하부·L5 상부 골성 종판과 두 종판 사이 공간 | 잠정 |
| 측정 방식 | 모델에서 유효 지지·접촉 영역을 정하고 길이·폭·높이·각도 산정 | 검토 중 |
| 윤상돌기 | 모델에서 경계 식별이 어려워 이를 임의 측정 기준으로 확정하지 않음 | 검토 중 |

## 측정 항목과 의미

| 측정 항목 | 확인 대상 | 주의점 |
|---|---|---|
| 케이지 길이 후보 | 삽입 방향을 고려한 종판의 유효 전후 지지 범위 | 척추체 외곽 최대 길이와 동일하다고 가정하지 않음 |
| 케이지 폭 후보 | 실제 배치 위치의 종판 지지 가능 폭 | 단순 최대 가로폭과 구분 |
| 케이지 높이 후보 | L4 하부–L5 상부 사이의 추간 높이와 복원 목표 | L4·L5 높이를 각각 재서 결정하는 것이 아님 |
| 전만각 후보 | 두 종판의 상대 경사 및 수술 정렬 목표 | 한 종판의 단독 각도와 구분 |

**미완료:** 모델 단위·좌표계 확인, 수술 접근 방향/케이지 배치 위치 설정, 유효 측정 경계 확정, 실제 수치 기록. 측정 완료 전 규격을 최종 선정하지 않는다.
