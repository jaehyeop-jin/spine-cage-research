# 척추 모델 및 측정 기준

| 항목 | 현재 판단 | 상태 |
|---|---|---|
| 모델 | 기존 FEBio L4–L5 척추 모델 | 활용 방향 확정 |
| 원본 CT | 미확보 | 확인 필요 |
| 측정 대상 | L4 하부·L5 상부 골성 종판, 두 종판 사이 공간 | 검토 중 |
| 측정 기준 | 삽입 위치에서의 유효 지지 범위·추간 높이·상대 경사 | 검토 중 |
| 윤상돌기 | 모델에서 경계를 식별하기 어려워 직접 측정 기준으로 확정하지 않음 | 미확정 |

## 규격별 확인 항목

| 규격 | 확인할 형상 | 유의사항 |
|---|---|---|
| 길이 | 케이지 삽입 방향의 종판 유효 지지 범위 | 척추체 외곽 최대 길이를 그대로 사용하지 않음 |
| 폭 | 실제 배치 위치에서의 종판 지지 폭 | 최대 가로폭과 구별 |
| 높이 | L4 하부와 L5 상부 사이의 추간 높이 | L4·L5 각각의 뼈 높이를 의미하지 않음 |
| 전만각 | 두 종판의 상대 경사 | 한쪽 종판의 단독 경사와 구별 |

**현 상태:** 측정 경계 및 실제 수치 미확정. 측정값이 나오기 전에는 최종 케이지 규격을 선정하지 않는다.
