# 05. 해석 결과 및 검증

**현재 상태: 미착수 / 등록된 해석 결과 없음 (2026-10-19 기준)**

이 폴더에는 해석 실행 이후의 결과와 검증 근거를 기록한다. 값·그래프·결론을 임의로 채우지 않는다.

| 등록 대상 | 기록할 핵심 정보 |
|---|---|
| 실행 조건 | 모델·CAD 버전, 재료/하중/접촉, 소프트웨어 설정 |
| 검증 | 수렴 여부, 외력–반력 평형, 메시 민감도 |
| 결과 | 조건별 변위·강성·관심영역 변형률 및 단위 |
| 비교 | 공통 영역·동일 산출식으로 조건 간 차이 |
| 결론 | 적용 범위, 수치 불확실성, 해석으로 입증하지 못한 항목 |
