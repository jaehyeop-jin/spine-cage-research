# 01. 연구 개요

## 연구 방향

L4–L5 추간체에 삽입되는 일반 경사형 케이지와 골성 종판·해면골의 지지거동을 **유한요소해석**으로 검토한다.

**기존 블록도에 기록된 구체적 질문:** 종판 및 해면골의 강성 변화가 전체 케이지 지지응답에 미치는 개별 효과와 복합 효과를 어떻게 구분할 수 있는가?

> 위 구체적 질문·2×2 물성 수준은 기존 블록도에 포함된 안이다. 연구 목적, 변수, 시험 범위를 최종 적용 전에 다시 대조한다.
