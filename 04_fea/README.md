# 04. 유한요소해석

## 분석 준비현황

| 항목 | 현재 기록 | 상태 |
|---|---|---|
| 해석 모델 | L4–L5와 일반 경사형 케이지 | 준비 중 |
| 주요 비교 변수 | 종판·해면골 탄성계수 (기존 상세 블록도의 2×2 설계안) | 최종 검토 필요 |
| 하중 | 기존 도식에 축방향 압축 400 N 기재 | 검토 기준안 |
| 구속 | 기존 도식에 L5 하부 고정 기재 | 검토 기준안 |
| 접촉 | 케이지–골성 종판 마찰 접촉 등 | 접촉 계수·알고리즘 검토 필요 |
| 수치 검증 | 접촉 수렴, 메시 민감도, 외력–반력 평형 | 수행 전 |
| 결과지표 | 축방향 변위·할선강성·종판/해면골 변형률 | 기존 계획안 |
